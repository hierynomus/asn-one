== What is asn-one
asn-one is a pure Java implementation of an ASN.1 encoder and decoder. It supports the BER and DER encoding rules of the bytestream. It is designed to be as lightweight as possible by having minimized the external dependencies. It only depends on the SLF4J logging API.

== Getting asn-one
To get asn-one, you have two options:

. Add a dependency to asn-one to your project.
. Build asn-one yourself.

Binary releases of asn-one are not provided here, but you can download it https://central.sonatype.com/artifact/{asn_groupid}/asn-one/{asn_version}[straight from the Maven Central repository] if you want to.

== Depending on asn-one
If you're building your project using Maven, you can add the following dependency to the `pom.xml`:

[source,xml,subs="verbatim,attributes"]
----
<dependency>
  <groupId>{asn_groupid}</groupId>
  <artifactId>asn-one</artifactId>
  <version>{asn_version}</version>
</dependency>
----

If your project is built using another build tool that uses the Maven Central repository, translate this dependency into the format used by your build tool.

== Reading ASN.1
Input must be BER or DER encoded. PEM files (`-----BEGIN ...-----`) need to be Base64 decoded first.

[source,java]
----
ASN1InputStream is = new ASN1InputStream(new BERDecoder(), bytes);
ASN1Sequence certificate = is.readObject();
----

By default, decoding is strict: an object with a UNIVERSAL tag that asn-one has no specific type for causes an `ASN1ParseException`, so a successful parse means every object was understood.
To read any well-formed structure instead, use a lenient decoder, which keeps such objects as an `ASN1UnknownObject` with their raw contents:

[source,java]
----
ASN1InputStream is = new ASN1InputStream(BERDecoder.lenient(), bytes);
----

The setting also applies to tagged objects whose contents are decoded later on, through `ASN1TaggedObject.getObject()`.

== Building asn-one
. Clone the asn-one repository.
. Run the command `./gradlew clean build`.
